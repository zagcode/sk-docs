# Specialist Dashboards Certification

The Sankhya Developer platform offers a specialized certification program focused on dashboard development. According to the documentation, this credential aims to "fornecer aos clientes e parceiros Sankhya a aquisição de conhecimentos e habilidades fundamentais para a criação, manutenção e desenvolvimento de dashboards."

## Program Structure

The curriculum spans 12 hours across five modules, progressing from foundational concepts through advanced implementation:

- **Module 1** covers first-level dashboard construction, including gadget building and value/geographic/chart components
- **Modules 2-3** develop intermediate and advanced dashboard features
- **Module 4** addresses finalization and launcher configuration
- **Module 5** provides bonus content on all dashboard components

## Eligibility Requirements

Candidates must complete the Associate Framework Data Dictionary certification and possess knowledge of SQL and relational databases.

## Assessment Process

Successful certification requires 90% proficiency and completion of a practical exam involving dashboard development demonstrating component functionality, onclick functions, and XML file export capabilities.

The program operates as a self-directed online course through Sankhya University, with technical support available through the [Sankhya Developer community portal](https://comunidade.sankhya.com.br/c/certificacao-specialist-dashboards/118).
